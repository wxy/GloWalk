## How to sign

To sign this Agreement:

1. Open a pull request against this repository that adds a file
   `CLA-signatures/<your-github-username>.md` containing:

   ````markdown
   I, <your-github-username>, agree to the GloWalk Individual Contributor
   License Agreement in CLA.md.
   ````

2. A maintainer will review and merge it.

Once the file is merged, a check on your other pull requests will pass. You only
need to sign once. Maintainers (repository collaborators with write access or
higher) are exempt from signing.
